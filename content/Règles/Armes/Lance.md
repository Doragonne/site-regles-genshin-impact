### Description
Les armes d'hast sont celles qui ont la vitesse d'attaque la plus élevée en plus de disposer d'une bonne portée.

---
### Attaque normale 
<font color="#7f7f7f">Le joueur peut effectuer une attaque normale lors d'une action d'attaque.</font>
2d4 DGT Physiques. Les deux jet peuvent être sur différents ennemis

### Attaque chargée
<font color="#7f7f7f">Pour effectuer une attaque chargée, le joueur doit utiliser toute son action de mouvement ou utiliser son action pour se préparer (concentration) a attaquer au prochain tour. Si le joueur se fait toucher pendant sa concentration, elle est interrompu. </font>
L'attaque chargée de la lance permet se projeter rapidement en avant, infligeant 2d4 DGT Physique à tous les ennemis traversés sur une courte distance. 

### Attaque plongeante 
<font color="#7f7f7f">Pour effectuer une attaque plongeante, le joueur doit déjà etre dans les airs avec tous ses points de mouvement restant.</font>
Utilise sa lance pour améliorer son aérodynamisme, infligeant 2d8 DGT Physique a une cible se trouvant sous le joueur.

---
### Manieur d'œil divin
En combat, vous pouvez utiliser vos [[PE (Particules Elémentaires)]] de votre Œil Divin pour améliorer votre art martial. 

Plus vous manier votre arme, plus vous apprenez a l'utiliser de différentes manières. En montant en Constellation vous obtenez de nouvelles possibilité d'actions.

Vous pouvez réalisé l'une des actions suivantes selon votre Constellation : 

#### Constellation 0
##### Danse céleste
	Aptitude
	x fois par tour
Vous pouvez dépenser 2 [[PE (Particules Elémentaires)]] pour utiliser l'action Se [[Désengager]] ou l'action [[Foncer]] via une action bonus au cours de votre tour, de plus votre distance de saut est doublée pour le tour (distance de saut suffisante pour faire une attaque plongeante).

---
#### Constellation 3
##### Déluge de coup
	Action Bonus
	1 fois par tour
Vous pouvez utiliser 3 [[PE (Particules Elémentaires)]] pour effectuer une action de mouvement ou une action d'attaque en tant qu'action bonus. 

---
#### Constellation 5
##### Esprit sain dans un corps sain
	Aptitude
	1 fois par tour
**Au début de votre tour**, vous pouvez vous mettre dans une posture de combat jusqu'à votre prochain tour. 

**Posture Défensive** : vous pouvez augmenter votre DEF d'autant de [[PE (Particules Elémentaires)]] que vous consommez pour le faire. De plus, si une attaque vous rate de moins de 5 pendant votre posture, vous pouvez effectuer une attaque d'opportunité sur la cible (une fois par tour).

**Posture Dynamique** : vous pouvez augmenter votre DEX d'autant de [[PE (Particules Elémentaires)]] que vous consommez pour le faire. 

**Posture Sage** : vous pouvez augmenter votre SAG d'autant de [[PE (Particules Elémentaires)]] que vous consommez pour le faire. 

**Posture Méditative** : Vous devez posséder tous vos point de mouvement. Vous vous concentrez pour augmenter votre CA d'autant de [[PE (Particules Elémentaires)]] que vous consommez pour le faire. Pour chaque attaques portées contre vous qui ne vous atteint pas, vous vous soignez de 1 DV (dé de vie) en PV. Vous ne pouvez plus vous déplacer avec cette posture.
Si une attaque vous touche, cela brise la concentration et met donc fin à votre posture. Cependant, vous pouvez faire un jet de sauvegarde de DEX pour esquiver le coup. Si vous réussissez, vous ne prenez que la moitié des dégâts.
