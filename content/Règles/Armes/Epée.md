### Description
Les épées à une main sont l'intermédiaire des épées à deux mains et des lances en terme de dégâts et de vitesse d'attaque.


---
### Attaque normale 
<font color="#7f7f7f">Le joueur peut effectuer une attaque normale lors d'une action d'attaque.</font>
1d6 DGT Physiques

### Attaque chargée
<font color="#7f7f7f">Pour effectuer une attaque chargée, le joueur doit utiliser toute son action de mouvement ou utiliser son action pour se préparer (concentration) a attaquer au prochain tour. Si le joueur se fait toucher pendant sa concentration, elle est interrompu. </font>
Effectue plusieurs attaques rapides devant le joueur, infligeant 2d6 DGT Physique

### Attaque plongeante 
<font color="#7f7f7f">Pour effectuer une attaque plongeante, le joueur doit déjà etre dans les airs avec tous ses points de mouvement restant.</font>
plonge avec son épée infligeant 2d6 DGT Physique a une cible se trouvant sous le joueur

### Manieur d'œil divin
En combat, vous pouvez utiliser vos [[PE (Particules Elémentaires)]] de votre Œil Divin pour améliorer votre art martial. 

Plus vous manier votre arme, plus vous apprenez a l'utiliser de différentes manières. En montant en Constellation vous obtenez de nouvelles possibilité d'actions.

Vous pouvez réalisé l'une des actions suivantes selon votre Constellation : 

#### Constellation 0
##### Solide sur les appuies
	Action Bonus
	x fois par tour
Vous pouvez augmenter une de vos [[Compétences]] ou votre CA d'autant de [[PE (Particules Elémentaires)]] que vous consommez pour le faire. Si vous devez faire un jet de sauvegarde, vous pouvez, par une réaction, augmenter le résultat de votre jet de sauvegarde d'autant de [[PE (Particules Elémentaires)]] que vous consommez pour le faire

---
#### Constellation 3
##### Gare à vous
	Action Bonus
	x fois par tour
Vous pouvez augmenter une de vos [[Statistiques principales]] (sauf le TX CRIT) d'autant de [[PE (Particules Elémentaires)]] que vous consommez pour le faire. 
Ou bien, dépensez 2 [[PE (Particules Elémentaires)]] pour augmenter votre TX CRIT de 1 point. Vous pouvez effectuer cela plusieurs fois.

---
#### Constellation 5
##### Maitre d'arme
	Action Bonus
	x fois par tour
Vous pouvez augmenter une de vos [[Caractéristiques Principales]] ou celles d'un allié que vous pouvez voir d'autant de [[PE (Particules Elémentaires)]] que vous consommez pour le faire. 
Vous pouvez aussi utiliser 3 [[PE (Particules Elémentaires)]] Vous ajouter votre Bonus de maitrise a un jet contre la mort.




Le joueur peut utiliser 1 PE par tour pour améliorer ces jets d'attaques, de sauvegarde, ou ses dégâts. Ce bonus se traduit par un dé dont la valeur change avec le niveau de constellation comme suit :

| Constellation | PE / tour |
| ------------- | --------- |
| C0            | 1d4       |
| C1            | 1d4       |
| C2            | 1d4       |
| C3            | 1d6       |
| C4            | 1d6       |
| C5            | 1d6       |
| C6            | 1d8       |
