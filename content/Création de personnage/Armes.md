
Les joueurs devront ensuite choisir un type d’armes parmi les suivantes, qui sera le type d’arme du personnage **a vie**.

Chaque type d’arme a une caractéristique principale qui lui est propre, et permet aux joueur d’effectuer 3 types d’action : Une attaque normale, chargée ou plongeante

Pour lancer une attaque normale, chargée ou plongeante, les dés lancés sont en rapport avec la caractéristique principale de l’arme, et les effets varient selon le type d’arme comme suit :
