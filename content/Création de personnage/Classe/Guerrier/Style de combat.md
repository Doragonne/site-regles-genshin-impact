Votre expérience vous a permis de développer une manière personnelle de combattre.

Choisissez **un style de combat** parmi les suivants :

- **Arme lourde :** Si vous utilisez une Claymore, vous pouvez relancer un dé de dégâts dont le résultat est inférieur ou égal à 2. Vous devez conserver le nouveau résultat.
- **Précision :** Si vous utilisez un Arc, vous obtenez **+1 à vos jets d'attaque**.
- **Duelliste :** Si vous utilisez une Épée, vous obtenez **+2 aux dégâts** de vos attaques.
- **Combattant polyvalent :** Si vous utilisez une Lance, vous obtenez **+1 à votre défense**.
