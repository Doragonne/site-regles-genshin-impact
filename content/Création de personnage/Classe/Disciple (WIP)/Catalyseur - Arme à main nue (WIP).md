### Description
Les catalyseurs sont des armes magiques, toutes leurs attaques sont élémentaires. L'élément dépend de celui de l'utilisateur.


---
### Attaque normale 
<font color="#7f7f7f">Le joueur peut effectuer une attaque normale lors d'une action d'attaque.</font>
1d6 élémentaires. L'élément dépend de l'œil divin du porteur

### Attaque chargée
<font color="#7f7f7f">Pour effectuer une attaque chargée, le joueur doit utiliser toute son action de mouvement ou utiliser son action pour se préparer (concentration) a attaquer au prochain tour. Si le joueur se fait toucher pendant sa concentration, elle est interrompu. </font>
Attaque en AOE qui inflige 1d6 DGT Élémentaires à tous les ennemis dans la zone.

### Attaque plongeante 
<font color="#7f7f7f">Pour effectuer une attaque plongeante, le joueur doit déjà etre dans les airs avec tous ses points de mouvement restant.</font>
Le joueur devient une comète élémentaire, infligeant 1d6 DGT Élémentaires à tous les ennemis dans une petite zone

---
### Manieur d'œil divin
Le joueur peut utiliser ces PE pour améliorer la valeur de sa carte pour une valeur inférieur ou supérieur équivalent au niveau de constellation du joueur comme suit :

| Constellation | PE / tour |
| ------------- | --------- |
| C0            | 2         |
| C1            | 2         |
| C2            | 3         |
| C3            | 3         |
| C4            | 4         |
| C5            | 5         |
| C6            | 6         |
